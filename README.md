
# Superstore Sales & Profit Analysis

## Project Overview
End-to-end Data Analytics project using Python, SQL,
Power BI, and Excel-compatible CSV data.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- MySQL
- Power BI
- ReportLab

## Dataset
Sample Superstore Dataset
- Total Records: 9,994
- Total Sales: $2.30M
- Total Profit: $286.40K
- Profit Margin: 12.47%

## Project Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- SQL Business Analysis
- 10 Data Visualizations
- Automated PDF Report Generation
- Interactive Power BI Dashboard
- KPI Analysis

## Key Business Insights
- West is the top-performing sales region.
- Technology generates the highest profit.
- Consumer is the largest customer segment.
- Standard Class is the most-used shipping mode.
